Task-1 of the week at DecodeLabs: The To-Do List
Project 1 is the "Logic Phase" of our training, focusing on the DNA of backend engineering—Data Management. 
Instead of building complex algorithms, this task required me to master how to store, modify, and view multiple items in a single variable
Technical Highlights:
IPO Model Architecture: I designed the program to follow the Input, Process, and Output model, ensuring clear backend logic. 
Data Structure Implementation: I mapped dictionaries as "Table Rows" and used lists as the "Database Table," simulating how professional database systems manage information. 
CRUD Functionality: The program supports full Create (Add), Read (View), and Delete (Process) operations.
Memory Management: I utilized the iterator protocol to create temporary views of the system's state , and leveraged Python’s dynamic array efficiency for task storage.
